# Shonan Institute of Technology Pack

A Tomo pack for international students at Shonan Institute of Technology (湘南工科大学, shonan-it.ac.jp).
Community-made; not affiliated with or endorsed by the school.

| File | Purpose |
|---|---|
| `pack.yaml` | Metadata, permissions, trusted sources, quick topics |
| `hatch.yaml` | First-run questionnaire; identifiers become `{{PLACEHOLDERS}}` |
| `soul.md` | What the assistant needs to know about this school |
| `skills/` | Hermes skills: `campussquare` (CampusSquare portal, read-only) |
| `data/` | Build script for local indexes (output is not committed) |
| `evals/` | Regression questions |
